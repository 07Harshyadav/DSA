# Patterns

This folder contains pattern-based problems.

The main purpose of solving these problems is to build a strong understanding of:

* Loops
* Nested loops
* Conditions
* Row and column logic
* Pattern observation
* Problem-solving skills

## Topics Covered

* Star Patterns
* Number Patterns
* Character Patterns
* Pyramid Patterns
* Inverted Patterns
* Symmetric Patterns
* Hollow Patterns
* Mixed Patterns

## Approach

While solving each pattern.

-> Nested loop.
1. For the outer loop, count the numbers of lines.
2. For the inner loop, focus on the columns & connect them somehow to the rows.
3. Print them "*" inside the inner for loop.
4. Observe Symmetery (optional).


The goal is to understand the **logic behind the pattern rather than memorizing the code**.
